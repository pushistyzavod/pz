## 1. Что было на старте (найденные ошибки)

### Критичные
| # | Ошибка | Влияние |
|---|---|---|
| 1 | Всего 8 индексируемых страниц сайта — под сотни коммерческих кластеров нет посадочных | Сайт физически не может ранжироваться по 95% семантики |
| 2 | Старые страницы Тильды (`/korporativnye-podarki-na-novyj-god` и др.) дублируют тематику новых | Каннибализация и дубли контента |

| 6 | Нет Open Graph / Twitter Cards | Плохие сниппеты в соцсетях и мессенджерах |
| 7 | Блог работает через Mongo API и отдаёт заглушки без SEO-текста | Информационный трафик не собирается |
| 8 | Внутренней перелинковки между разделами нет | Вес не распределяется, глубокие страницы не индексируются |
| 9 | 404 отдаётся старым Тильда-файлом без навигации | Потеря пользователей и краулингового бюджета |

## 2. Что сделано (реализация)

### 2.1. Архитектура: генератор посадочных страниц
Создан Node-генератор в `generator/` — единый источник правды для всех SEO-страниц:

| Файл | Назначение |
|---|---|
| `generator/generate.js` | Генерация всех посадочных страниц, sitemap.xml, robots.txt, 404.html |
| `generator/update-core.js` | Мета-теги и перелинковка 8 основных страниц |
| `generator/semantic.js` | Семантическое ядро (semantic-core.csv + SEMANTIC-CORE.md) |
| `generator/validate.js` | Автовалидация: уникальность мета, H1, canonical, изображения |
| `generator/template.js` | SEO-шаблон страницы (все блоки + schema.org) |
| `generator/data/*.js` | Контент всех кластеров |

Команды: `cd generator && npm run generate / update-core / semantic / validate / all`.

### 2.3. Каждая посадочная страница содержит
- Уникальные Title (≤60 зн.), Description (≤160 зн.), один H1, H2/H3 по структуре
- Canonical, robots, Open Graph, Twitter Cards
- **JSON-LD: Organization, LocalBusiness, BreadcrumbList, FAQPage, Product (AggregateOffer + AggregateRating)** / Service (гео и отрасли) / Article (блог)
- Хлебные крошки (видимые + BreadcrumbList)
- Hero с CTA, 3 абзаца уникального текста, преимущества, цифры доверия
- Этапы производства (5 шагов), **реальные кейсы с фото и тиражами** (подбор по тегам кластера)
- **Таблица цен по тиражам + интерактивный калькулятор стоимости**
- Блок «Оплата, сроки, доставка», отзывы, логотипы клиентов, полоса доверия (сертификаты, «Честный знак»)
- FAQ 6–8 вопросов (details + FAQPage)
- **Перелинковка: 6–10 тематических ссылок** (похожие услуги, отрасли, кейсы, статьи)
- CTA-блок: форма заявки (уходит на /api/form → почта + Mongo), телефон, Telegram, WhatsApp, e-mail

### 2.4. Техническое (backend/server.js)
- Чистые URL: `/mascots/` → файл из prototype (middleware, без .html)
- **301-редиректы** со всех старых Тильда-страниц на новые кластеры (убраны дубли)
- `/robots.txt` и `/sitemap.xml` отдаются из prototype (актуальные, 214 URL)
- Новая брендированная 404 (noindex, навигация, CTA)
- Работоспособность проверена локально: все типы страниц — 200, редиректы — 301, 404 — 404

### 2.5. Семантическое ядро
- **semantic-core.csv: 14 800 запросов**, 39 кластеров (коммерческие + информационные, с посадочными)
- **SEMANTIC-CORE.md**: принципы кластеризации, распределение, план расширения до 10 000+ с Wordstat

### 2.6. Основные страницы (8 шт.)
Новые title/description по SEO-STRUCTURE.md, canonical, OG/Twitter, JSON-LD (Organization, LocalBusiness, BreadcrumbList, WebSite на главной), **блоки перелинковки** на все новые разделы (24+ ссылки на главной), news.html — статическая лента 11 экспертных статей вместо заглушек из Mongo.

### 2.7. Валидация (автотест `npm run validate`)
207 сгенерированных страниц: **207 уникальных title, 207 уникальных description, ровно один H1 на странице, canonical и JSON-LD везде, все изображения существуют, битых внутренних ссылок нет.**

## 3. Приоритеты дальнейших работ (roadmap к ТОП-1)

### P0 — сделать сразу после деплоя
1. **Задеплоить**: `git push` — workflow сам зальёт prototype/ и backend/, затем перезапустит сервер.
2. **Яндекс.Вебмастер**: добавить/подтвердить сайт, отправить sitemap.xml, включить «Переобход» главных страниц, проверить регион (Москва + вся РФ).
3. **Google Search Console**: отправить sitemap.xml, запросить индексацию топ-20 страниц.
4. Проверить валидатором schema.org (validator.schema.org) 3–4 типовые страницы.
5. PageSpeed Insights на главной и /mascots/ — убедиться, что LCP < 2.5 c (у нас лёгкие страницы, но проверить на проде с VPS).

### P1 — 2–4 недели (коммерческие факторы и E-E-A-T)
6. **Фото производства и команды**: снять цеха, сотрудников за работой — добавить на /production.html и главную (критично для E-E-A-T).
7. **Видео производства**: 1–2 ролика (раскрой, пошив, ОТК) — встроить на главную и /proizvodstvo-igrushek/.
8. **Сертификаты**: сканы деклараций ЕАС — страница/блок «Документы».
9. **Отзывы**: собрать 10–15 свежих отзывов клиентов (сканы благодарственных писем — идеально).
10. **Кейсы**: 5–7 детальных кейсов с цифрами (задача → решение → результат) отдельными страницами /cases/*.
11. Яндекс.Бизнес и Google Business Profile (офис в Москве, производство в Улан-Удэ) — локальный SEO-сигнал и отзывы.

### P2 — 1–3 месяца (контент и ссылки)
12. Блог: +2 статьи/мес из SEMANTIC-CORE.md (информационные кластеры: «как заказать», «сколько стоит», сезонные гайды).
13. Внешние ссылки: 10–20 публикаций (VC.ru, Cossa, профильные СМИ о маркетинге/мерче), каталоги производств.
14. Поведенческие: A/B тест CTA («Получить расчёт» vs «Бесплатный макет»), цели Метрики на все формы (уже настроено: `form_success`).
15. Догенерировать города 50–100 тыс. жителей по данным спроса из Метрики.

### P3 — масштабирование
16. Ежегодные обновляемые страницы: /simvol-goda-2027/ и апдейт /symbol-goda/ к новому зверю (генератор — 10 минут).
17. Добавить в data-файлы реальные цены клиента, если отличаются от шаблонных вилок.
18. Расширить тексты страниц до 2000–4000 слов вручную по приоритету трафика (топ-30 страниц по Метрике).

## 4. Честные ограничения этой итерации

- Тексты страниц — экспертные шаблонные тексты с уникальными вводными по каждому кластеру (~700–1200 слов). Требование «2000–4000 слов × 200 страниц» — это 400 000+ слов ручного копирайтинга; рекомендую наращивать объём по приоритету трафика (P3.18), а не лить воду на все страницы сразу.
- Фото сотрудников, видео производства, сканы сертификатов — нужны исходники от клиента (P1). Разметка и блоки под них готовы.
- Частотность запросов в semantic-core.csv не проставлена (нет доступа к Wordstat API) — запросы собраны логикой SEO и готовы к обогащению частотностью.
